# انرژی کاشان (Flutter، اندروید ۷+)

## ساخت APK با گیت‌هاب
1. یک مخزن جدید در GitHub بسازید و محتوای همین پوشه را در ریشه‌ی آن آپلود کنید
   (شامل `lib/`، `pubspec.yaml` و پوشه‌ی مخفی `.github/`).
2. در تب Actions روی «Build APK» بروید و Run workflow بزنید (با هر push هم خودکار اجرا می‌شود).
3. پس از پایان، فایل `kashan-energy-apk` را از بخش Artifacts دانلود کنید.

تمام ارقام مصرف، قبض و هزینه «داده‌ی نمونه» هستند و در برنامه با برچسب «داده‌ی آزمایشی» مشخص شده‌اند.
پرداخت، بازیابی رمز و اطلاعیه‌ی قطعی برق نیازمند بک‌اند/API رسمی‌اند و هنوز وصل نشده‌اند.
